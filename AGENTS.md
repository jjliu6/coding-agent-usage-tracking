# Agent notes

## UI / UX previews (required)

凡是界面、动效、文案可见的改动，PR 和回复里都必须带预览图或预览视频。

That means any change a person can see in the product: layout, motion, copy, color, empty or error states, the mascot, the landing page. Ship a preview **image** or **video** in both:

1. The pull request description
2. The reply to whoever asked for the change

Put the same artifacts on the GitHub PR so review comments sit next to the preview. Code-only work (parsers, storage, tests with no visible UI) does not need a visual preview.
