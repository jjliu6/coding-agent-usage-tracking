Coding Agents 额度（中文个人版）1.0.1

这是给你自己用的中文包，没有合入开源英文仓库。
已包含 Grok 周额度修正：按 SuperGrok 的 33% used → 显示 67% 剩余，
并带上 聊天 / 构建 / 自动 / 绘图 分类条。

安装（Chrome 加载已解压的扩展）：
1. 解压本 zip，得到一个文件夹
2. 打开 chrome://extensions
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选中解压后的文件夹
5. 点工具栏图标，再点「刷新」拉取额度

若之前装过英文版，可以先移除英文版再加载这一份，避免两个图标搞混。
刷新时会短暂打开 Claude / Codex / Cursor / Grok 的额度页，抓完会自己关掉。
